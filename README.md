# Mr.Chicken Linz – Single-Page Web-Entwurf

Moderne, mobiloptimierte Website für **Mr.Chicken** in Linz (Wiener Straße 91, 4020 Linz).

## 🚀 Live-Demo via GitHub Pages
Nach der Aktivierung in den GitHub-Repository-Einstellungen unter:
👉 `https://tdsin16.github.io/mrChicken/`

## 🍗 Features
- **Mobile-First Clickdummy**: Speziell konzipiert für Smartphone-Präsentationen
- **Direkte Vorbestellung**: 1-Tap Telefon-Button (`tel:+436604449897`)
- **Bestseller-Teaser**: Broasted Chicken, Zinger Burger Menü, Shawarma Teller, Falafel Box
- **Standort & Navigation**: Integrierte Karte & One-Tap Google Maps Route
- **Superschnelle Ladezeit**: Schlankes HTML5 mit Tailwind CSS (kein JavaScript-Overhead)
- **SEO-optimiert**: Strukturierte Gastronomie-Daten via Schema.org (JSON-LD)

## 🛠️ Lokale Ausführung
Im Projektverzeichnis:
```bash
python -m http.server 3333 --bind 0.0.0.0
```
Auf dem Smartphone im selben WLAN öffnen:
`http://<Deine-WLAN-IP>:3333`
